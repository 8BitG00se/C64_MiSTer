OCTOPHONIC FUSION build @BUILD@ - one card, flashed once from the PC
=====================================================================

What it is: a whole MiSTer on one SD card image (MiSTer @REL@, set up by MiSTer's own Mr. Fusion
@MRF@) with Octophonic 64 already in: Core 10, Octophonic Main, the browser, the front screen, and
OCTOCODE (edit, compile and run) in games/C64/Tools. Power on and it goes straight into Octophonic 64.

NEW IN THIS BUILD
 - Core 10: OCTOSCOPE (OctoVIC version 5) - a real oscilloscope of every SID voice (all 24, and each
   SID's whole output), phase-locked so a note stands still, drawn by OctoVIC as a layer. OctoPlay
   build 4 (from the website) shows it. Everything from Core 9 is in too:
 - Core 9: EXACT 50 Hz on by default (50.000 frames a second, so captures have no hitches; the
   original PAL 50.12 Hz is an option), OctoVIC FINE SCROLL (quarter-pixel layer scrolling), and
   games/C64/Apps is now games/C64/Tools (your files are moved over).
 - The front screen: the new KERNAL-box logo (OCTO5). A screen on the Octophonic firmware is
   updated by itself the first time the card starts - no batch file to click. The screen goes dark
   for about 4 minutes while it updates (the MiSTer keeps running); octophonic/update.log says so.
 - MiSTer.ini: vsync_adjust=2, so HDMI follows the core's 50 Hz (smooth on the CRT and HDMI).
 - HOT KEYS (Core 9 on): from anything running, HOLD for about a second -
     SHIFT+F1  back to the KERNAL start screen     SHIFT+F2  RUN/STOP+RESTORE
     SHIFT+F4  wipe memory and restart              (SHIFT+F3 is spare; the MiSTer menu is F12)
   A quick tap still does what it always did.
 - Tools/SPEC.PRG: what this machine has - core, OctoVIC, SIDs, SDRAM size, REU, PAL/NTSC.
 - My Chips: your own measured SID chips (6581 5084, 6581 3184, 8580 3591, 8580 4687). The core menu's
   My Chips page loads three of them at once (Chip A, B and C) and gives every one of the eight SIDs its
   own line: Chip A, Chip B, Chip C or the core's own. Chip C is its model and filter curve only. The
   same chips are behind OctoPlay's F3/F5.
 - Tools/TESTCARD.PRG: a test card (crosshatch and circles) for setting up a CRT or checking HDMI.
The other folders are empty, ready for your own files: demos, tools and games come from the
website (GitHub).

You need: a micro SD card of 2 GB or more (everything on it will be wiped), a card reader, and
balenaEtcher or Rufus on the PC.

WITH BALENAETCHER (easiest)
 1. Install balenaEtcher from https://etcher.balena.io
 2. "Flash from file" -> pick  Octophonic Fusion build @BUILD@.img
 3. "Select target" -> pick the SD card. CHECK THE SIZE so you are sure it is the card.
 4. "Flash!" and wait for it to finish and verify. Windows may say the card needs formatting:
    click Cancel - do NOT format it.

WITH RUFUS
 1. Run Rufus (https://rufus.ie). Device: the SD card (check the size).
 2. Boot selection: SELECT -> Octophonic Fusion build @BUILD@.img
 3. START. If it asks how to write, choose "DD Image". OK to the warning that the card is wiped.
 4. When it says READY, close Rufus. If Windows offers to format the card: Cancel.

FIRST POWER-ON
 - Card into the MiSTer, switch on. The Octophonic setting-up picture comes up (navy, yellow
   OCTOPHONIC 64) while it grows the card to its full size and puts everything on it. Then the
   screen can go BLACK for several minutes while it writes - that is normal.
   LEAVE IT ALONE FOR 10 MINUTES. Switching off now leaves a half card (black screen for good).
   It restarts by itself into Octophonic 64.
 - Not sure it worked? Card back into the PC and double-click "Check card.bat" (it only reads).
   It says CARD OK, or which file is missing - then flash again.
 - From then on, every power-on goes straight into Octophonic 64.

SENDING FILES FROM THE PC (FileZilla) - works from the first power-on, nothing to set up
 - Plug the MiSTer into the network (cable; for Wi-Fi see OPTIONAL below). In FileZilla's bar at the top:
     Host: MiSTer     Username: root     Password: 1     Port: 21     then Quickconnect
   If "MiSTer" is not found, type its address instead (a number like 192.168.x.x: the MiSTer menu,
   Alt+F1, shows it, and so does your router's list of devices).
 - You land in /root. Go to /media/fat - that is the SD card. Your files go in /media/fat/games/C64:
   .d64 in Disks, demos (the .prg with its .reu) in Demos, and so on. Drag them across, then F1 on
   the Octophonic start screen finds them. Port 22 instead of 21 is the same thing encrypted (SFTP).
 - KNOW WHAT THIS IS: it is MiSTer's own file server, the same on every MiSTer, and root / 1 is
   MiSTer's standard login - not a secret. Anyone on your home network can read, change or delete
   every file on the card with it. That is fine at home. Do not use the MiSTer on a network you do
   not trust, and never forward ports 21 or 22 to it on the router. For your own password, MiSTer's
   own security_fixes.sh script (github.com/MiSTer-devel/Scripts_MiSTer) sets one; its ftp_off.sh
   switches the file server off.

THE FRONT SCREEN'S FIRMWARE (once, after the first power-on, with the MiSTer on the network)
 - The logo at power-on works with the Octophonic screen firmware you already have.
 - For each demo's OWN animation the screen needs firmware OCTO4: double-click
   "Update front screen firmware.bat" (password 1 if it asks). The MiSTer is NOT restarted, but
   THE FRONT SCREEN GOES DARK FOR ABOUT 4 MINUTES - leave it alone. Its old firmware is saved
   first and put back if anything goes wrong. Then run Demos - Night City build 3 and watch it.

WHAT TO CHECK
 - Power-on: white noise, then the Octophonic start screen; the front screen shows the logo.
 - The sound is louder than before (same volume setting on the TV/soundbar).
 - F1, pick a demo with a .reu: soft blue raster bars in the border while it loads, no flashing.
 - F1 and F3 show their own titles; in the browser M mounts a .d64 in drive 8 (it does not run),
   and the start screen shows drive 8; F8 has SHOWCASE.
 - After the firmware update: Night City, DNA Wave, Pendulum Wave and Mona Lisa each play their
   own animation on the front screen; CTRL+F12 (or Esc held) brings the logo back.

GOING BACK TO CORE 7 (if Core 8 is wrong): Core 7 is not on this card. Flash Octophonic Fusion
build 6 again - it is Core 7 as before.

OPTIONAL, before the first power-on: with the card still in the PC, a drive called OCTOFUSION
shows up. Put a wpa_supplicant.conf (Wi-Fi) or samba.sh on it and they are set up too.
(samba.sh switches on a Windows share of the whole card, open to your network - only if you want one.
FileZilla does not need it.)

THE MISTER'S OWN MENU is still there: C=+F1 (on a PC keyboard Alt+F1) at READY or in the browser.
Every MiSTer script (Scripts folder) works as normal.

GOING BACK TO A PLAIN MISTER: delete octophonic/os.ini and put a ; in front of the
bootcore= line in MiSTer.ini; MiSTer.orig is the stock MiSTer program and menu.rbf.stock the stock
menu core, if you want those back too.
